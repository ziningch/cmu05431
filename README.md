I am using React + Vite template

This project is intended to be a hierarchical graph generator tool, where users can drag components from the left toolbar to draw
shapes, arrows, and text on the canvas

The bottom tool bar contains the flowchart shape tool, textbox tool, sticky notes tool, connector tool, and concept map tool.

The textbox tool contains a bold function that allows bolding and unbolding of the text in the textbox. It also allows for size selection via a size popup offering three different sizes.

The sticky-note tool contains a popup for selecting which color the sticky note is. The default sticky is a square but the user can resize it.
